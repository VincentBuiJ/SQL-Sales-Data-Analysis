
# Sales Data Analysis

## Project Overview
This project analyzes sales data using SQL and SQLite.

The goal is to identify sales trends, compare product performance, and understand revenue by category.

## Tools Used
- SQLite (Database)
- SQLiteStudio (Database Management Tool)
- SQL (Query Language)

## SQL Skills Demonstrated
- SELECT
- WHERE
- GROUP BY
- ORDER BY
- COUNT
- SUM
- AVG
- MAX and MIN
- DISTINCT
- LIKE
- LIMIT

## Key Findings
- Total revenue: $5,025
- Electronics revenue: $3,425
- Furniture revenue: $1,600
- Best-selling product by quantity: Mouse (15 units)
- Highest-revenue product: Laptop ($2,400)

## Business Insights
- Electronics generated more revenue than Furniture.
- Mouse had the highest number of units sold.
- Laptop generated the highest product revenue.

- Sales_Analysis.sql: SQL queries used for the analysis.
